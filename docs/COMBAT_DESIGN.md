# 跨界纪元 — 战斗系统设计

参考：《艾尔登法环》架势条 + 《黑神话：悟空》连击节奏

## 玩家操作

| 输入 | 动作 | 精力消耗 | 备注 |
|------|------|----------|------|
| 鼠标左键 | 轻击 | 12 | 0.38s，中段判定 |
| 鼠标右键 | 重击 | 28 | 0.68s，高架势伤害 |
| Q | 锁定/取消 | — | 20m 内最近敌人 |
| Ctrl | 闪避 | 18 | 0.45s 无敌帧 |
| Shift | 冲刺 | 持续 | 战斗中被限制 |

## 数值

- 玩家 HP：100
- 轻击伤害：18 / 架势 +12
- 重击伤害：42 / 架势 +28
- 架势满 → 敌人硬直 2s

## 敌人分布

| 位置 | 敌人 | HP | 行为 |
|------|------|-----|------|
| 枢纽东侧 | 训练木人 | ∞ | 不反击，练手 |
| 灰白森林 | 影之战士 ×2 | 120 | 追击+近战 |
| 魔法遗境 | 魔法构装体 | 180 | 慢速高伤 |
| 米勒荒原 | 轨道无人机 ×2 | 90 | 快速低血 |

## UE5 实现要点

- `UCrossrealmCombatComponent` 已预留接口
- 使用 Animation Notify 触发 Hit Trace
- 锁定用 `AActor*` + SpringArm 插槽偏移
- UI 用 UMG ProgressBar 绑定 CurrentHealth / CurrentStamina
