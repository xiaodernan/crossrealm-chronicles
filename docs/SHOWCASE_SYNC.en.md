## Deployment path (W-Z99, unified)

**Pages source is already fixed to workflow-artifact** — every push to `main` auto-deploys the whole site; the gh-pages branch is no longer part of the live path.

This repo ships `.github/workflows/pages.yml`, run on every push to `main`:

1. `npm ci`
2. `npm run build` with `BASE_PATH=/crossrealm-chronicles/game/` (the game lives under `/game/` — mandatory, or chunk URLs 404)
3. Assembles `_site/`:
   - `/` → `creative/showcase.html` (the latest-results single page)
   - `/game/` → `dist/` (the playable build, always fresh)
   - `/guide.html` (player booklet) · `/tapestry.html` (compendium, zh) · `/tapestry.en.html` (compendium, en) · `/favicon.svg`
   - pushed via `actions/upload-pages-artifact` → `actions/deploy-pages@v4` → `https://xiaodernan.github.io/crossrealm-chronicles/`
4. **Nothing to configure**: the Pages source is the workflow itself; every push redeploys, no manual steps, no branch trickery.
   The legacy `showcase.yml` job (pushing `_site/` to the gh-pages branch) wrote a branch nobody could actually serve — it was retired in favor of a single unified `pages.yml`.

Playable build URL: **`https://xiaodernan.github.io/crossrealm-chronicles/game/`** — this is where the personal site’s “enter the game” link should point.

`creative/showcase.html` opens standalone locally too — it is a self-contained HTML with zero external dependencies; `npm run build && npm run preview` works for the whole bundle locally.

## Personal-page live sync (W-Z92)

The “Crossrealm Chronicles” card on `https://xiaodernan.github.io/` should land visitors on *the freshest* build, not a snapshot. Two redundant paths:

1. **Runtime live read**: the page fetches `raw.githubusercontent.com/xiaodernan/crossrealm-chronicles/main/docs/latest.json?ts=<now>` (CORS `*`; cache-busted), falling back to the committed `assets/crossrealm/latest.json` in the pages repo.
2. **Weekly fallback**: `.github/workflows/sync-latest.yml` here re-runs `scripts/build-latest.mjs` and pushes `docs/latest.json` back to `main` every Monday; the pages repo’s `sync-crossrealm.yml` mirrors it into `assets/crossrealm/latest.json` (staggered by 30 minutes).

Every number in `docs/latest.json` (commits / test files / i18n keys / corpus sources / novel chapters) is derived from the live repository at sync time — nothing is hand-copied or drifts. After a milestone push you can run `Sync latest.json fact pack` manually from the Actions tab to refresh immediately.
