# Crossrealm Chronicles — Creative Bible (EN mirror)

> English mirror of `creative/README.md`. The creative directory holds **all off-game assets** of Crossrealm Chronicles — images, the novel, the film script, the OST, the posters, the official compendium — and it stays in sync with the game body forever.
> All counts mirror the game’s real truth: **110 echoes** + **40 mother-theme badges** + **3 cross-boundary echoes**.
