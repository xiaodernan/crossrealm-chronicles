# 《跨界纪事：锚火守夜人》

**类型**：位面奇幻 / 黑暗史诗 / 元叙事
**改编自**：Crossrealm Chronicles（跨界纪事）
**卷十三**：新火 —— 第七百年

## 九十 · 墨

小火在小火把册序翻到最后一页的时候，灶火已经亮了三个月。

那一天也是冬至。

外头下了很大的雪。母亲从后山挑了一捆柴进来，放在灶边，歇了一会儿。

小火最后一眼看见阿石的眼睛——阿石指着册子最后一行空格。

他懂了。

他把笔拿起来。

阿石没有替他磨墨——母亲也走到了灶边，停住。

灶火响了一下。

小火用他小小的手握住笔，在墨上一蘸，对准那空白的最后一页。

他写的不是他见过的字。

他写的是：

火。

不是「火」，不是「火」——是灶火他自己在火里看到的那个字。那不是一个汉字，是一个方向，是灶火借他的手，把它自己写了出来。

墨迹落在纸上的时候，整屋的六百年的火——所有同时跳了一下。

母亲把手放到胸前。

院子里，火种树同时示了示。

很远很远的远方，云很满，不亮也不暗。

灶火——一下——

跳了很高。

很高的光。

很亮的光。

白奶奶——她从没有出现过——她出现了一下。

阿石看见火里站着一个人——个很老、很老、但脚底深扎地、风骨好像风的人影——她看了一眼小火，一眼又一眼看阿石，最后一眼看了整间屋子——然后消失了。

灶火跳了一下，又跳了一下，整个——火矮下来。

子时的时候灶火忽然安静了下来。

小火的嘴里不知道什么时候流了一滴泪。

阿石坐下来，给他抹掉。

"看见了谁？"

小火擦了眼泪，还没答。

他说：

"我看见六百年的人。"

阿石沉默了。

小火接着说：

"他们都在这里。"

他又说：

"我能闻到他们的手。"

他站起来。

阿石站起来。

灶火没跳。

小火小心合上书册。

院子里的雪大了一寸。

灶火整夜都烧得很稳。

灶火——也要守下去。
