# 跨界纪事 · 跨媒体宇宙（Creative Bible）

> English mirror: [`README.en.md`](README.en.md)
本目录为 **Crossrealm Chronicles（跨界纪事）** 的衍生创作资产，与游戏代码独立，可直接用于宣传、同人、配乐参考。
所有计数以游戏真实内容为准（当前：**110 枚次元回声** + **40 枚母题徽章** + **3 枚跨界回声**）。

## 📁 目录

| 路径 | 内容 |
|------|------|
| `novel/` | 长篇小说**七章 + 序言 + 八番外**（锚火守夜人 · 《炉火给你的回信》 · 《看守的回信》·《林渡给看守的回信》·《后来者的回信》·《火之前》·《换班》·《下次再坐》 · 《漏灯记》） |

```
creative/music/soundtrack.html
```

- **25 首**程序化 Web Audio 实时预览（**不再只有 6 首**；四个 Disc 全覆盖——位面之心 / 奥术荒原 / 逆相混沌 / 回声全集 + 彩蛋单曲）
- **年鉴单页**——浏览器直接打开 `tapestry.html`：游戏×小说×电影×OST 同源考据，谢幕碑照录 17 行 epitaph
- 每首给出 BPM、调性 / 角色一句话；同一首每次播放表现一致
- 点击曲目即可播放；切换曲目自动停止前一首；"STOP" 按钮重置为"未选择"
