1 欢迎Welcome to Crossrealm Chronicles

《跨界纪元》是一款完全运行在浏览器里的位面动作角色扮演——无 Boxes，无插件，干净的 HTML + JS，打开就打。你将操控一位「位面行者」，探索七座位面枢纽连成的世界，从基础的采集与炼制，到五个 Boss 的完整叙事线，最后在没有所谓对错——却各自有重量的结局里做出选择。

它同时是一套完整的工程作品：Spring Cloud 微服务、Redis 台账、消息队列、世界事件报讯、110 枚次元回声、40+ 成就与 17 枚母题终章；另外还有小说、电影剧本、25 首可播放 OST 与一座「年鉴」单页网站——它和游戏永远同源，永远沉默。

1 WelcomeWelcome to Crossrealm Chronicles

Crossrealm Chronicles is a full ARPG that runs entirely in your browser — no installers, no plugins, just a clean HTML/JS build you open and play. You are a Planewanderer: seven realms joined by a light-frame; gathering → forging → combat → duels → a finale where both answers are right and neither is free.

It is also a complete engineering artifact: Spring Cloud microservices, Redis ledgers, message queues, world-event feeds, 110 echo entries, 40+ achievements and a 17-mother “keeper” ending — plus a novel trilogy, a 142-minute film script, a 25-track playable OST and an official compendium site. One canon, forever consistent.

2 安装与运行30 秒

  1. 克隆本仓库 git clone https://github.com/xiaodernan/crossrealm-chronicles.git
  2. 进入目录：cd crossrealm-chronicles
  3. 安装：npm install
  4. 开发模式：npm run dev → 浏览器打开 http://localhost:5173
  5. 正式产物：npm run build，产物在 dist/ 目录，任意静态服务器即可
存档保存在浏览器 localStorage 中（键名 crossrealm_save_v21），不占用任何网络。跨设备迁移：在游戏中按 Escape → 设置 → 导出存档，然后在新设备上导入。存档损坏时，游戏会自动兜底到最小可用状态，绝不丢失进度。

2 Install & Runin 30 seconds

  1. Clone the repo: git clone https://github.com/xiaodernan/crossrealm-chronicles.git
  2. Enter it: cd crossrealm-chronicles
  3. Install: npm install
  4. Dev: npm run dev → open http://localhost:5173
  5. Prod build: npm run build — output in dist/, serve with any static file server
Saves are kept in the browser’s localStorage under crossrealm_save_v21 — zero network calls. Moving devices: Esc → Settings → Export save, then import on the new machine. Corrupt save? The game migrates back to a safe baseline instead of locking you out.

4 战斗入门从"会打"到"会玩"

  1. 开打前：先按 Q 锁定 Boss。Q 是眼睛，F 是心。
  2. 打法节奏：轻击（左键）连击攒伤害，连击高了接普攻终结（闪屏特效）；压力大时用右键重击打断。
  3. 弹反窗口：Boss 红闪 = 将要出重击。F 弹反成功：无伤硬直 Boss，并回自己的资源。
  4. Boss 出手语义：
    • 影界守护者 — 横斩两连，弹反后反手
    • 大奥术师 — 紫弹扇形，闪避后背刺
    • 奇点领主 — 吸力→冲刺，停顿时机
    • 时线执政官 — 时间冻结，冻结结束前出手
    • 混沌裂隙领主 — 弹幕，贴近短时输出
  5. 死亡也是进度：Boss 给出奖励/提示用于整理战斗，重打不惩罚。

4 Combat 101from “surviving” to “playing”

  1. Before you engage: lock on with Q. Q is your eyes. F is your heart.
  2. Rhythm: light-attack combos build damage; high combo → finisher (screen flash). Pressure spike? Heavy attack with RMB to interrupt.
  3. Parry window: a boss’s red flash = a heavy incoming. Land F: free damage + refill your resources.
  4. Boss grammar:
    • Shadow Warden — twin slashes: parry, then counter
    • Archmagus — purple fan: dodge, then turn to flank
    • Singularity Herald — gravity pull + dash: punish the pause
    • The Timeline Inspector — time-freeze: strike before it ends
    • Chaos Overlord — bullet hell: close in, short bursts
  5. Death counts as progress: death cues you toward the instakill patterns; retries are free.

8 Ending & Embersboth answers are right

After the Anchor falls there is no correct route — only the walking you’re willing to do.

  • “Keep the flame.” — your light goes on; cleared achievement “Echo-keeper”, and the start page carries an extra gold pill: Echo-keeper · the flame endures.
  • “Walk it out.” — the journey gathers itself under you; nobody else receives the baton, but your choice is still seen.

After either choice: the Embers Journal tab lights its epitaph + 17 stardust inscriptions (your 17 = seven ticks). Each line reads as Fire, Choice or Hello — three ways the flame writes you home.

关闭 = 零网络，零后台请求，与离线完全一致。在线层从不强制注册。玩家可随时关闭。

10 Online Layer & Fireside Rumorsoff by default · opt-in only

Turn it on in Settings → Online partners (persisted in localStorage) and the game joins a small cloud of real-time services:

  • World-event feed — boss defeats, season rollovers, trial-crown swaps, speedrun-crown swaps and double crowns — pinned to the Advisor board (“Fireside rumors”).
  • Echo-keeper badge — clear the game and the start page carries an extra gold pill: Echo-keeper · the flame endures.
  • Unread gold dot on the Advisor FAB — lights up when there’s something new to read.

Off = zero network, zero background requests; identical to offline. No accounts ever required. Toggle at will.

12 FAQ / 故障排查跑不起来就看这页

黑屏 / 白屏

「你的浏览器拒绝了 GLES」→ 在设置里把画质调「低」，GPU 子模块自动关闭光照细节。持续跑 60fps≈打开 perf HUD。

无法锁定鼠标（Pointer lock 失败）

浏览器需要 HTTPS 或 localhost 才允许锁定——按 http://localhost:5173 而不是直接双击 HTML 文件；F11 全屏有帮助。

存档没了

全部数据都在你自己的浏览器里（localStorage），不上传任何服务器。导出/导入存档请去「Esc → 设置」。

怎么开报讯台

只有自己运行后端服务（Spring Cloud 网关）时，「在线伙伴」开关才会产生网络请求；开发模式默认端口 8080。不开 = 零网络，不需要你所在局域网有任何东西。

运行 dev 卡顿

开发模式未压缩体积较大。正式使用：npm run build 后用 npm run preview，或任何静态服务，帧率远好于 dev。

12 FAQ / Troubleshootingread me if anything feels off

Black / white screen

If your GPU disagrees with GLES: open Settings → Graphics and set quality to Low; the pipeline drops lighting detail. Watch the perf HUD (F9) to confirm stability.

Pointer lock fails

Browsers only allow pointer-lock on https or localhost — open http://localhost:5173, don’t double-click the built file. F11 full-screen helps.

Where did my save go?

Saves live entirely in your browser’s localStorage — nothing is ever uploaded. Esc → Settings to export/import.

How do I turn on the rumors feed?

Only when you’re running your own backend (Spring Cloud gateway): the “Online partners” toggle starts producing traffic. Default port 8080. Off = exactly zero network.

The dev server stutters

Dev mode is unminified on purpose. Use npm run build + npm run preview (or any static host) — it’s much faster.
